# Installation

Follow the [Prettier Java instructions](https://github.com/jhipster/prettier-java#readme), replacing `prettier-plugin-java` with `prettier-java-next-line`.

```sh
npm install --save-dev --save-exact prettier prettier-java-next-line
```

Load `prettier-java-next-line` as the plugin. Next-line braces need no option; use `braceStyle: "same-line"` to restore upstream placement.

## Prettier Next Line

To use next-line formatting for Prettier's built-in languages too, install [Prettier Next Line](https://github.com/motlin/prettier-next-line) under the name `prettier`:

```sh
npm install --save-dev --save-exact prettier@npm:prettier-next-line prettier-java-next-line
```

## Spotless Maven

Spotless expects a package named `prettier`, so alias the runtime fork and load the Java plugin by its published name.

```xml
<prettier>
	<devDependencies>
		<prettier>npm:prettier-next-line@3.10.0</prettier>
		<prettier-java-next-line>2.10.3</prettier-java-next-line>
	</devDependencies>
	<configFile>.prettierrc.json</configFile>
	<config>
		<parser>java</parser>
		<plugins>prettier-java-next-line</plugins>
	</config>
</prettier>
```
